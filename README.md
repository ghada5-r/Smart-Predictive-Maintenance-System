# 🚀 Smart Predictive Maintenance System

An AI-powered predictive maintenance system that helps industries predict machine failures before they happen using Machine Learning.

## 📌 Project Features
- Predict Maintenance Required
- Predict Failure Type
- Predict Remaining Useful Life (RUL)
- Detect Risk Factors
- Generate Smart Maintenance Recommendations
- Interactive Dashboard

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- SMOTE
- Machine Learning
